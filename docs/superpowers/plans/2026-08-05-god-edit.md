# God-Mode Direct Table Editing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When god mode is unlocked, every list page gains an "Edit table" toggle that turns mapped cells into type-aware inputs; each cell commits per-field PATCHes through the existing APIs.

**Architecture:** One shared descriptor-driven cell layer (`lib/godEdit.tsx`: `GodField`, `useGodEdit`, `GodCell`, toolbar toggle) + a small `godOnly` extension to `listTools.tsx`; each page exports a `GOD_FIELDS` table from its pure lib and routes `cellFor` through `GodCell`. Portal-only; zero API changes.

**Tech Stack:** React 18 + TS + vitest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-05-god-edit-design.md`.

## Global Constraints

- Repo root `/Volumes/Extreme SSD/Code Backups/BaseCampV3`; work happens on branch `god-edit` in the worktree `/Volumes/Extreme SSD/Code Backups/BaseCampV3-assets` (symlinked node_modules — never reinstall, never `git add` it; targeted adds only; delete stray `._*` files if tools trip).
- Verify each task: `cd portal && npm test && npm run build` — green + clean. Commit per task, trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- Writes go ONLY through each page's existing PATCH client method; never add API endpoints or bypass validation.
- The edit toggle renders ONLY when `godMode` (from `useAuth()`) is true. Write affordances still respect `can(resource,'change')` — GodCell takes `disabled` and pages pass `!canChange`.
- House rules: ComboBox for record-backed cells; native `<select>` only for tiny fixed enums/tri-state; `.chip`/list classes untouched when not editing; error copy comes from each page's existing error map, fallback `'Could not save.'`.
- Per-cell semantics: Enter/blur commits only if the value changed; Esc reverts; in-cell spinner while saving; on error stay in edit mode with red ring + message; PATCH response item replaces the row via `onRowSaved`.
- `godOnly` columns: hidden from ColumnsButton and never in the default visible set unless god mode is on; turning god mode off hides them again (drop them from `visibleCols`).
- Dual-unit cells (Makes/Models) send ONLY the edited side; blank → `null` (server clears partner). Reuse the page's numeric semantics from `modelPayload` — do not reimplement conversion client-side.

**Interfaces produced (Tasks 2–6 rely on these exact names):**

```tsx
// lib/godEdit.tsx
import { useState, type ReactNode } from 'react';
import { ApiError } from './api';
import ComboBox, { type ComboOption } from '../components/ComboBox';
import './../styles/god-edit.css';

export interface GodField<T> {
  column: string;                        // ColumnDef key; 'primary' | 'primary2' for the name cell
  field: string;                         // API field name sent in the PATCH body
  kind: 'text' | 'number' | 'combo' | 'select' | 'bool';
  fromRow: (row: T) => string;           // row -> input value ('' for null)
  toPatch?: (raw: string) => unknown;    // default: trimmed string, '' -> null
  options?: () => ComboOption[];         // combo/select sources (page lookups, lazily read)
}

export function defaultToPatch(raw: string): unknown {
  const v = raw.trim();
  return v === '' ? null : v;
}

export function numberToPatch(raw: string): unknown {
  const v = raw.trim();
  if (v === '') return null;
  const n = Number(v);
  if (Number.isNaN(n)) throw new Error('not_a_number');
  return n;
}

export function boolTriToPatch(raw: string): unknown {
  return raw === '' ? null : raw === 'yes';
}

export function useGodEdit() {
  const [editing, setEditing] = useState(false);
  return { editing, toggle: () => setEditing((e) => !e) };
}

export function GodEditToggle({ editing, onToggle, visible }: {
  editing: boolean; onToggle: () => void; visible: boolean;
}) {
  if (!visible) return null;
  return (
    <button className={`btn-ghost god-edit-toggle ${editing ? 'on' : ''}`}
            aria-pressed={editing} title="God mode: edit table directly"
            onClick={onToggle}>
      <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="1.7"
           strokeLinecap="round" strokeLinejoin="round" width="14" height="14">
        <path d="M17 3a2.85 2.85 0 1 1 4 4L7.5 20.5 2 22l1.5-5.5Z" />
      </svg>
      Edit table
    </button>
  );
}

export function GodCell<T extends { id: string }>({ row, gf, patch, onRowSaved,
                                                    errorMap, disabled }: {
  row: T;
  gf: GodField<T>;
  patch: (id: string, body: Record<string, unknown>) => Promise<T>;
  onRowSaved: (updated: T) => void;
  errorMap: Record<string, string>;
  disabled?: boolean;
}) { /* full implementation in Step 3 */ }
```

`GodCell` behavior (Step 3 implements): local `value` seeded from `gf.fromRow(row)` (re-seeded when `row` identity changes); text/number render `<input>`, `bool`/`select` render `<select>` over `options()` (bool uses Unknown/Yes/No with values ''/'yes'/'no'), `combo` renders `ComboBox`. Commit path: skip when unchanged; `toPatch` errors (e.g. `not_a_number`) show locally without an API call; otherwise `setSaving`, `await patch(row.id, { [gf.field]: mapped })`, `onRowSaved(updated)`. `ApiError` → message from `errorMap[err.code] ?? 'Could not save.'`, keep editing. Esc restores the seed value. Root span classes: `god-cell`, `saving`, `error` (+ `<span className="god-cell-msg">` under the input when error).

`listTools.tsx` changes: `ColumnDef` gains `godOnly?: boolean`; `ColumnsButton` gains optional `godMode?: boolean` prop and filters `columns.filter((c) => !c.godOnly || godMode)`; export helper `visibleColumnsFor(columns, visible, godMode)` → `columns.filter((c) => visible.has(c.key) && (!c.godOnly || godMode))` so pages drop god columns from the grid when god mode turns off without mutating state.

`god-edit.css`: `.god-edit-toggle.on` amber accent; `.god-cell input, .god-cell select { … amber-tinted background via color-mix(--accent) … }`; `.god-cell.error input { outline: 2px solid var(--c-red) }`; `.god-cell-msg { color: var(--c-red); font-size: 11px }`; `.god-cell.saving { opacity: .6 }`.

**Steps:** (1) write `godEdit.test.ts` covering `defaultToPatch`/`numberToPatch`/`boolTriToPatch` + `visibleColumnsFor` godOnly filtering — run, expect module-not-found; (2) implement `godEdit.tsx` + css + listTools changes; (3) full `GodCell` implementation; (4) `npm test` + `npm run build` green; (5) commit `feat(portal): god-edit shared mechanism`.
