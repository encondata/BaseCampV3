# Wiki Phase 1 (core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the wiki's core — spaces, folders, pages, files, inherited permissions, a live co-editing
Tiptap editor with Draft/Published and version history, presigned uploads with previews, `.docx`/`.md`
import, full-text search (including text inside files), trash, favorites — as a separate `wiki`
Docker image (+ `wiki-worker`) that signs in exactly like the portal.

**Architecture:** Data + REST live in the main FastAPI app under `/wiki/*` (tables `wiki_*`, migration
0074). A new `wiki/` npm package holds the SPA (`wiki/web`, Vite/React, reusing the portal's Login and
AuthContext through the `@portal` alias) and a Node server (`wiki/server`: Express static + Hocuspocus
`/collab` + `/internal/render`). A `serversherpa wiki-worker` process converts Office files to PDF
(LibreOffice), extracts text (pdftotext) and purges trash.

**Tech Stack:** Python 3.13 / FastAPI / SQLAlchemy 2 async / Alembic / Postgres 16 (FTS + pg_trgm) /
boto3 (MinIO, DO Spaces); Node 20 / TypeScript 5.6 / React 18.3 / Vite 5.4 / vitest 3.2 / Tiptap 2.x /
Hocuspocus 2.x / Yjs 13.6 / Express 4; mammoth + marked (import), diff (history).

Algorithm (spec §3) — implement exactly:
```python
async def _level(self, space_id, chain: list[uuid.UUID]) -> str | None:
    # chain = node.path + [node.id]  (root first). Space-level grants start the set.
    p = self.p
    if not p.can_view_wiki:
        return None
    if p.is_admin:
        return "manage"
    await self._load_space(space_id)        # grants for the space + (id, inherit, has grants) of nodes that
                                            # have grants or inherit=false, archived_at
    current = list(self._space_grants[space_id])           # grants with node_id NULL
    managers = [g for g in current if g.level == "manage"]
    for nid in chain:
        own = self._node_grants[space_id].get(nid, [])
        if nid in self._breaks[space_id]:                   # inherit_permissions = false
            current = list(own) + managers                  # space managers never lose access
        else:
            current = current + list(own)
    best = None
    for g in current:
        if grant_matches(p, g.principal_type, g.principal_id):
            best = max_level(best, g.level)
    if best and self._archived[space_id]:
        best = "view"
    return best
```
`grant_matches`: `everyone` → True; `internal` → `is_internal`; `role` → id in roles; `access_group` → uuid in group_ids; `person` → equals person_id; `client` → in client_ids; `partner` → in partner_ids. Invalid uuids never match (no exception).

Memoize per `(space_id, tuple(chain))`. `levels_for_nodes` groups by space and loads each space once. `effective_grants` returns each grant in the final set with `source` = `space` or the node that contributed it (title looked up), and a `principal_label` resolved by a helper `principal_labels(db, grants)` (role name, group name, person display name, client/partner name; "Everyone who can sign in", "All internal staff").
