# Database Health Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A developer-only Health tab on `/dev/database` with database summary, who's connected, per-table statistics with Vacuum & analyze, and file storage usage.

**Architecture:** Every process names its DB connections (`application_name`) through `db/engine.py`. Read-only Postgres catalog queries live in `api/src/serversherpa/devtools/health.py`, exposed by a new router `api/routes/health.py` at `/devtools/health`. Vacuum runs on an autocommit connection. The portal adds `components/dev/HealthTab.tsx` as the fifth tab.

**Tech Stack:** FastAPI, SQLAlchemy async + asyncpg, boto3 (storage listing), pytest; React + TypeScript, vitest.

**Spec:** `docs/superpowers/specs/2026-10-09-db-health-design.md` — binding.

## Global Constraints

- Routes: `GET /devtools/health/summary`, `GET /devtools/health/connections`, `GET /devtools/health/tables`, `POST /devtools/health/tables/{name}/vacuum`, `GET /devtools/health/storage`. `devtools:view` for GETs, `devtools:change` for vacuum.
- Never return the database host, user, password, query text, client address or role names.
- Vacuum: table name must match a current `public` table from the catalog (404 `unknown_table` otherwise); 409 `testing_session_active` during an unfinished DB Testing session (reuse the Cleanup check); autocommit connection; identifier safely quoted; audit `db.vacuum` with `{"table", "duration_ms"}`.
- Storage: grouped by first path segment ("(root)" for keys without "/"); 502 `storage_unavailable` on storage errors.
- Connection names: `serversherpa-api` for the API; `serversherpa-<cli-command-name>` for each worker; default `serversherpa`.
- UI flags connection groups whose oldest query/transaction is over 300 seconds.
- Portal: house idioms only (`.sysconf-tab`, `init-panel sysconf-card`, `eyebrow-sm`, `page-hint`, `mini-btn`, `btn-solid`, `chip`, `dir-list` + `ColHead` + `listGridStyle` with column floors for the Tables list, `RowActionsMenu` for row actions, `pf-error`). American English. Manual Refresh only — no polling.
- Never commit `api/src/serversherpa/_dev_reload.py`. Never `git stash`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## How to run things (worktree `.claude/worktrees/db-health`)
